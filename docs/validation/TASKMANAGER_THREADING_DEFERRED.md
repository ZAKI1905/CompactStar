# Deferred TaskManager concurrency work

The external-dependency migration qualifies TaskManager with exactly one
thread. No TaskManager threading implementation is changed.

The migration predeclaration records shared sequence state protected by
per-object mutexes, thread-count-dependent output, and a four-thread run
that changed at least one stellar mass. This is not a multithreaded
scientific authority. A separate task must reproduce and resolve ownership,
ordering and synchronization before thread-count equivalence can be claimed.
It must retain the one-thread T1/T2 references as the scientific comparison.

CONFIND 2.0's deterministic evaluator executor may offer a later performance
opportunity. It does not replace TaskManager's stellar grid generation in
this candidate. No concurrency redesign or new parallel campaign is
implicitly authorized by the dependency migration.
